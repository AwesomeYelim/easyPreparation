# autoshorts — 설교 라이브 → 쇼츠 (사람 확인 3곳)

모델이 판단 초안(후보·제목·자막 교정·스톡 선택)을 만들고, 사람이 체크포인트에서 고르고, 확정된 레시피(`autoshorts.py`)로 렌더한다.
찬양 부분(준비찬양, 오후찬양예배)을 자르는 일은 입력과 위험이 달라 **별도 스킬(예정)** 로 다룬다. 이 스킬은 설교 쇼츠만 다룬다.

## 언제 쓰나
- 사용자가 `/autoshorts <유튜브 URL>`, "예배 영상으로 쇼츠 만들어", "이번 주 쇼츠 후보 뽑아줘" 등으로 요청할 때.
- 입력은 유튜브 라이브/다시보기 URL 하나. 자동 실행(예배 영상이 올라오면 세션이 무인으로 시작)일 때의 규칙은 아래 "자동 실행으로 시작된 경우".

## 전제 (로컬 기기 전용: 윈도우 또는 맥)
- `yt-dlp`, `ffmpeg` 가 PATH 에 있어야 한다. 없으면 설치 전에 사용자에게 묻는다(윈도우 `winget install yt-dlp.yt-dlp Gyan.FFmpeg`, 맥 `brew install yt-dlp ffmpeg`).
- 한글 폰트 나눔고딕 ExtraBold 사용. 윈도우는 `C:\Windows\Fonts`, 맥은 `~/.config/autoshorts/fonts/`, 환경변수 `AUTOSHORTS_FONTS_DIR` 로 바꿀 수 있다.
- 자동 시작: `watch.py`(같은 폴더)가 새 주일예배(일요일 13~22시)와 지난 영상 백로그(하루 1편)를 감지해 이 스킬을 켠다. 설정 `~/.config/autoshorts/config.json`, 상태 `~/.local/state/autoshorts/`. 맥은 launchd 로 예약.
- 클라우드 세션은 유튜브 봇 차단으로 영상을 못 받는다 → PC 로컬에서만 실행. 한글 폰트도 클라우드엔 없다.
- 작업 폴더 `<작업루트>\<영상ID>\`(예: `C:\workspace\autoshorts-work\<영상ID>\`)에 영상·자막·스톡·결과물을 둔다. `src.mp4` 가 이미 있으면 다운로드를 생략한다. **영상은 저장소에 커밋하지 않는다.** 시안은 대화로 전송한다.
- `autoshorts.py`(이 폴더, 파이썬 표준 라이브러리만 사용, `python` 으로 실행):
  - `fetch <URL> --out <작업폴더>`: 자동 자막(json3)을 받아 `<작업폴더>\subs\sermon.txt`(시:분:초 줄 텍스트)로 저장. 아직 실전 검증 전.
  - `render <spec.json>`: 사양으로 ASS(`workdir\clip.ass`)를 만들고 ffmpeg 렌더. 컷어웨이 규칙(3초 미만, 간격 3초 미만, 스톡 1/3 초과, 마지막이 스톡 아님)을 어기면 경고를 출력한다. 샘플 클립으로 검증 완료(수동 렌더와 프레임 동일).
  - 윈도우 경로의 `:` 때문에 필터의 `fontsdir` 는 작은따옴표로 감싸야 한다(코드 반영됨).

## 절차

### 0. 준비
1. 영상 다운로드: `yt-dlp -f "137+140/bv*[height<=1080]+ba" --merge-output-format mp4 -o src.mp4 <URL>`. 봇 차단이면 `--cookies-from-browser chrome` 제안.
2. 자동 자막: `autoshorts.py fetch <URL> --out <작업폴더>` 로 줄 시각 텍스트를 만들어 전체를 읽는다.
3. 설교 구간(찬양·광고·기도 제외)을 정한다. 방송 화면 하단 박스에서 설교 제목·설교자·본문을 읽어 둔다(프레임 1장 추출).

### 1. 후보 제안 (자동) → 체크포인트 1
자막 전체를 읽고 **선정 기준**으로 후보 3~5개를 목록으로 보여 준다. 후보마다:
- 제목 2줄(1줄 흰색·2줄 하늘색, 각 10자 안팎, 호기심 훅)
- 구간(원본 시각, 초 단위)과 길이(30~45초 권장, 60초 이내)
- 유형(경구·대조·목록·질문)과 한 문장 요약(20자 이내)
- **민감 플래그**: 성도 일화·개인 식별 가능·정치/경제·타 민족/종교 언급 → "목사님/사용자 확인 필요, 공개 금지"
- **의심 자막**: 오인식 후보 줄과 교정안. 확신이 없으면 해당 구간 3초 오디오(`ffmpeg -ss <t> -i src.mp4 -t 3.5 -vn -c:a aac x.m4a`)를 대화로 보낸다.

**체크포인트 1 — 사용자가 확인**: 만들 후보 선택, 구간 시작·끝 타이밍, 자막 교정(특히 고유 표현), 제목 문구. 답이 올 때까지 렌더하지 않는다. 질문은 yes/no 로 답할 수 있게 쓰고 응답 맨 끝 한 줄을 `?` 로 끝낸다(폰에서 답할 수 있게 질문지에 올린다).

### 2. 렌더 (자동) → 체크포인트 2
1. 컷 분할: 교정한 줄을 **10자 이내 컷**으로 나눠 `templates/header.ass` 스타일로 ASS 를 만든다(`render` 가 사양에서 생성). 강조 단어는 노랑 `{Y}…{/}`.
2. 스톡 선정: 문장 의미가 직접 맞는 장면만(규칙 아래). 컷어웨이는 2~3개.
3. `autoshorts.py render <spec.json>` 로 렌더. 이어 붙이는 클립은 사양의 `segments` 를 둘로 준다.
4. 결과 프레임 5장 이상(제목, 컷어웨이 경계, 끝)을 직접 확인한 뒤 영상을 대화에 보낸다.

**체크포인트 2 — 사용자가 확인**: 영상 내용·컷어웨이·제목·끝 처리. 수정 지시는 즉시 반영해 다시 렌더하고, 반복되는 취향 수정은 레시피 값(`autoshorts.py`)을 고친다.

### 3. 업로드 메타데이터 → 체크포인트 3 (직접 업로드)
- 쇼츠마다 제목·설명·태그를 아래 "업로드 메타데이터" 규칙으로 만들어 대화에 보여 주고 승인받는다. 태그는 글자 수를 세어 500자 이내인지 함께 적는다.
- 승인되면 `upload.py` 로 올린다(파이썬 표준 라이브러리만, ep 앱 코드와 무관). 처음엔 `private` 으로 올리고 `--status` 로 처리 결과를 확인한 뒤 사용자 지시가 있을 때 `--set-public` 으로 공개한다(성도 일화 클립은 목사님 확인 전 공개 금지).
  - 큐 JSON(`items[]`: key, file, title, description, tags, privacy, status=ready)을 만들어 `upload.py --queue <큐.json>` 으로 일괄 업로드. 성공하면 status 가 uploaded 가 되고 video_id 가 적힌다. 단일 파일은 `upload.py <영상> --title T --desc-file D --tags a,b --privacy private`.
  - 인증 파일은 저장소 밖 `~/.config/autoshorts/`(또는 `AUTOSHORTS_GOOGLE_DIR`)의 `google_oauth.json`, `youtube_token.json`. 토큰이 만료되면(`invalid_grant`) 이 기기에서 `upload.py --login-listen` 을 띄워 두고 `--login-url` 주소를 브라우저에서 승인한다.
  - 쇼츠 "관련 동영상"(풀영상 연결)은 API 로 설정 불가 → 설명 링크가 기본.

## 자동 실행으로 시작된 경우
예배 영상이 올라오면 트리거가 세션을 무인으로 시작하고 첫 메시지가 `/autoshorts <URL>` 일 수 있다. 이때는 사용자가 앞에 없다.
- 준비(0)와 후보 제안(1)까지만 진행하고, **체크포인트 1 에서 질문을 남기고 멈춘다.** 사용자가 답하기 전에는 렌더하지 않는다.
- 질문에는 후보 목록 요약과 의심 자막 오디오를 포함한다. 열린 질문은 응답 맨 끝 한 줄로 다시 적는다.

## 렌더 사양 (spec.json)
모든 시각은 **원본 영상 기준 초**. 구간이 둘이면 이어 붙인다(문장 끝 → 문장 시작 지점에서 자를 것).
```json
{
  "src": "C:/workspace/autoshorts-work/<ID>/src.mp4",
  "out": "C:/workspace/autoshorts-work/<ID>/E_v1.mp4",
  "workdir": "C:/workspace/autoshorts-work/<ID>/work",
  "segments": [[2120.40, 2158.60]],
  "title": ["감사의 히브리어는", "토다 = 고백하다"],
  "cues": [{"start": 2120.40, "end": 2121.90, "text": "{Y}감사{/}에 해당하는"}],
  "cutaways": [{"file": "C:/.../stock/bible.mp4", "start": 2136.40, "end": 2142.00, "ss": 1, "fadeout": true}],
  "pulses": [2123.24, 2128.0]
}
```
- `cues[].text` 의 `{Y}…{/}` 는 노랑 강조. 한 컷 10자 안팎.
- `cutaways`: 마지막 컷은 `"fadeout": false` 로 영상 끝까지. `ss` 는 스톡 영상에서 시작할 초.
- `pulses`: 슬로우 줌에 펀치를 줄 시각(선택).

## 후보 선정 기준
- **통과**: 한 문장(20자 이내)으로 요약되는 메시지. 경구·대조·목록·질문형 펀치라인. 제목 2줄이 그 문장 자체가 됨. 도입 설명이 거의 필요 없는 구간.
- **탈락**: 맥락 설명이 필요한 이야기형(성경 재진술, 일화). 도입부를 넣으면 60초가 넘고 빼면 맥락이 끊김. 점검 질문: "이 구간을 20자 한 문장으로 요약할 수 있나? 못 하면 탈락".
- 국가 경제·정치 언급, 성도 일화, 다른 종교·민족에 대한 단정은 기본 제외 후보.

## 자막 교정 규칙
- YouTube 자동 자막은 고유 표현을 자주 틀린다(예: "외상 빚"→"위에된 빛"). 문맥으로 고친 줄은 반드시 체크포인트 1 에서 사용자에게 알린다.
- 확신이 없으면 고치지 말고 오디오를 보낸다. 음성 대조 없이 의미가 바뀌는 교정은 하지 않는다.

## 스톡 영상 규칙 (컷어웨이)
- 소스: Pexels 무료 라이선스(상업 사용 가능, 출처 표기 불필요). 사이트 직접 요청은 403 → 브라우저 자동화로 페이지를 열어 DOM 에서 `videos.pexels.com/video-files/<ID>/<ID>-hd_1080_1920_*.mp4` 주소를 뽑아 그 CDN 주소를 직접 내려받는다. 공식 API 키는 아직 도입 전.
- **실제 해상도를 ffprobe 로 확인**한다(표기와 다르게 720x1280 으로 내려온 적 있음). 가능하면 1440 이상 파일을 받는다. 렌더 필터가 먼저 1080x1920 으로 맞추므로 크기가 달라도 동작은 한다.
- 개신교 분위기: 십자가상·촛불·묵주(가톨릭·정교) 검색 결과는 피한다. "holding bible", "empty chairs", "writing letter", "sunlight clouds" 처럼 구체 장면으로 검색한다.
- AI 생성 의심 영상(ID 3천만 이상, HTML 에 AIGC 표기) 제외. 실제 촬영본만.
- **배치 규칙**: 컷어웨이끼리 붙이지 않고 사이에 설교자 3초 이상, 10초당 1개 이하, 전체의 1/3 이하, 문장 경계에 맞춤, 마지막은 스톡으로 마무리, 전환은 알파 페이드 0.3초.

## 레이아웃 확정값 (요약, 정본은 `autoshorts.py`)
- 캔버스 1080x1920, 위 검은 띠 540, 영상 영역 1080x1380, 제목 2줄 y 325/450, 로고 240px @ (24,16), 진행 바 `0x00E5FF` 10px.
- 설교자 크롭 `crop=450:575:759:110`(카메라 고정, 얼굴 중심 x≈984, 방송 하단 성구 박스가 y 685부터라 685 위까지), 확대 후 슬로우 줌과 강조 펀치.
- 자막: 나눔고딕 ExtraBold 84, 흰색, 반투명 검은 박스, MarginV 290, 10자 이내.

## 업로드 메타데이터 (체크포인트 3 에서 사용)
- **제목**(100자 이내): `핵심 메시지 | 설교제목 · 설교자 (본문)`. 예) `토다 = 고백하다 | 먼저 자신을 주께 드리고 · OOO 목사 (고후 8:1-5)`.
- **설명**: 1~2줄 요약 + 풀영상 링크(해당 구간 시각 포함 `https://youtu.be/<ID>?t=<초>`) + 설교 정보 + 해시태그.
- **태그**: 태그 필드 총 500자 한도까지 채움(교회명, 설교자, 본문, 설교 제목, 주제어, 절기, 쇼츠, 설교쇼츠 등). 설명 해시태그는 15개 이하(초과하면 전부 무시, 앞 3개가 제목 위에 보임). YouTube 한도는 업로드 전 확인.
- Studio 의 쇼츠 "관련 동영상"(풀영상 연결)은 API 로 설정 불가 → 수동, 설명 링크가 기본.

## 하지 말 것
- 사용자 확인 없이 렌더 진행, 체크포인트 3 승인 없는 업로드, 성도 일화 클립 공개, 영상 파일 저장소 커밋.
- 체크포인트 1 전에 구간·자막·제목을 확정해 버리기.
- 음성 대조 없이 고유 표현 자막 교정.
- 공개 저장소다: 호스트명·키·개인 정보·사용자 PC 경로를 이 폴더의 파일에 적지 않는다.
